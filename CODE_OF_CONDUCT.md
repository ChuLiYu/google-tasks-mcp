# Code of conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and critique ideas rather than people. Harassment is not welcome. Report a problem through a [private report](https://github.com/ChuLiYu/google-tasks-mcp/security/advisories/new). The maintainer will review it and respond.
