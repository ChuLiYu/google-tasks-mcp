**核心想法：腦袋只負責決定，記憶交給系統。** 事情一旦進到可信的地方，並有下一步，就不必一直掛在心上。

### 每件事只放一個地方

| 東西 | 放哪裡 | 判斷方式 | 例子 |
|---|---|---|---|
| 固定承諾、硬性截止 | Google Calendar | 錯過時間會有實際後果 | 考試、看診、`截止：考試準備` |
| 下一個具體動作 | Google Tasks | 動詞開頭，一次坐下來做得完 | `做一回完整模考` |
| 想法、資訊 | 不放，或另外記 | 現在不用行動 | 「也許可以換工作」 |
| 理解、拆解、挑選 | LLM | 它不存資料，對話結束就不算數 | |

- **Tasks 的日期是「預計處理日」**，沒有時間、不會提醒，也不保證。要準時的事放 Calendar。
- **硬性期限用兩邊配合**：Calendar 放全天事件 `截止：名稱`，Tasks 放往回排的動作，備註寫 `期限：名稱 YYYY-MM-DD`。兩邊不一致時以 Calendar 為準，由 LLM 回報，不自動修正。
- **Calendar 只放真正的承諾**。專注時段只在你要求時才建立，否則行事曆很快就會失去可信度。

### 四個流程

安裝下面的技能後，直接這樣說就會觸發：

| 什麼時候 | 你可以說 | LLM 會做什麼 |
|---|---|---|
| 腦袋很滿 | 「清空腦袋：明天要繳費、下週三看牙、想學西班牙文⋯」 | 把每件事分到 Calendar、Tasks 或不處理，列一張表，你確認一次就全部寫入 |
| 有新期限 | 「規劃期限：3/20 前準備好考試」 | 查行事曆後往回排 3～7 個動作並預留緩衝，時間不夠就直說，確認後建立並讀回 |
| 每天開始 | 「今天做什麼」 | 列出固定行程和最多 3 件建議任務；過期的逐筆選今天做、改日期或放下 |
| 每週一次 | 「每週回顧」 | 看未來 14 天：有風險的期限、沒有下一步的期限、過滿的日子，最多問 3 個問題 |

### 減輕壓力的規則

- **過期只是資訊，不是失敗。** LLM 不統計你沒做到什麼；放下一件事也是正常結果。
- **每天最多 3 件建議。** 完成了可以再問，清單不必一次看完。
- **永遠有下一步。** 期限最怕只有名字。規劃完會指出第一個動作，並用「如果到了某時，我就開始某事」的方式定下來。
- **只問會改變結果的問題。** 少填欄位，大多數事情確認一次就好。

依據與限制：研究發現，為未完成的目標寫下具體計畫，可以消除它對注意力的干擾（[Masicampo & Baumeister 2011](https://bvbvf1.bib-bvb.de/vufind/PrimoRecord/cdi_proquest_miscellaneous_918752704)）；「如果⋯就⋯」的計畫也有助於執行（[Gollwitzer 2015](https://bpb-us-e1.wpmucdn.com/wp.nyu.edu/dist/c/6235/files/2019/02/gollwitzer-2015-setting-ones-mind-on-action.pdf)）。這些是心理學研究，不是本產品的量測；「最多 3 件」與「緩衝 2 天」是選定的預設值，可依自己的節奏調整。本專案未量測對生產力或壓力的實際影響。

### 需要的工具

| 工具 | 用途 | 如何取得 |
|---|---|---|
| 本專案 MCP | 讀寫 Google Tasks | [Claude 連線指南](CLAUDE_CONNECTION.md) |
| Google Calendar 連接器 | 讀取行程、建立事件 | Claude 的 Connectors 目錄；本專案不提供 Calendar 工具 |
| [`tasks-calendar-planner` 技能](../skills/tasks-calendar-planner/SKILL.md) | 上面四個流程與安全規則 | 見下方 |

兩個連接器要連到同一個 Google 帳號，否則行程和任務會對不上。

安裝技能：執行下面的指令產生 `dist/tasks-calendar-planner.zip`，到 Claude 的 **Customize > Skills > + > Create skill > Upload a skill** 上傳（[官方說明](https://support.claude.com/en/articles/12512198-how-to-create-custom-skills)；介面與方案以實際畫面為準）。

```sh
npm run skill:package
```

Claude Code 可改為把資料夾複製到 `~/.claude/skills/`。ChatGPT 不支援這個技能格式，可把內容貼進自訂指示，但尚未實測。

**使用上的取捨：** 寫入是連線授權後直接執行，模型若被任務備註或網頁內容誤導，可能直接修改任務，而且被覆寫的內容救不回來。技能要求模型把這些內容當資料看待，並在批次操作前確認，但這只是給模型的指引，不是安全保證。請用專用帳號，需要更嚴格時可改用逐筆核准（見 [Claude 連線指南](CLAUDE_CONNECTION.md)）。
